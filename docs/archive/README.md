# Archive: the quiz version

Until Faz 5 KERNEL PANIC was a quiz: five questions in 60 seconds. In Faz 6 (2 November 2026) the
questions left the game completely and the five stages took their place (see
[`../ROADMAP.md`](../ROADMAP.md) §2.3). The game does not read anything in this folder.

The two files are kept in Turkish, the language the questions were written and played in:

- `quiz-questions.tr.md` — the pool of 120 questions (its last state after four review rounds;
  about a third on technology, the rest general knowledge)
- `quiz-answer-check.tr.md` — the source check of the answers (Faz 4)
